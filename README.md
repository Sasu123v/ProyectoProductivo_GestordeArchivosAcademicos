# ProyectoProductivo_GestordeArchivosAcademicos
Proyecto Productivo del Técnico en Programación de Software. Aplicación web desarrollada con  HTML, PHP, MySQL y XAMPP.
Esta plataforma web solucionara la lentitud o la facilidad de la entrega de las tareas de los estudiantes de la Institucion Academica

- Visual Studio Code
## Base de datos
El script se encuentra en database/colegio_tecnico_palermo.sql
## Cómo ejecutar el proyecto
1. Copiar la carpeta en C:\xampp\htdocs\
2. Iniciar Apache y MySQL desde XAMPP.
3. Importar database/colegio_tecnico_palermo.sql en phpMyAdmin.
4. Configurar la conexión local a la base de datos.
5. Abrir http://localhost/ColegioTecnicoPalermo/
